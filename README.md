## Sistem Nilai Mahasiswa

# Deskripsi Proyek

Program ini adalah aplikasi sederhana berbasis Python yang menerapkan konsep Pemrograman Berorientasi Objek (OOP). Program ini berfungsi untuk mengelola data identitas mahasiswa serta pencatatan dan konversi nilai akademik.

# Tujuan
Menerapkan konsep OOP dalam pembuatan sistem yang dapat menyimpan, mengelola, dan menampilkan informasi nilai akademik mahasiswa secara terstruktur

# Fitur
- Menyimpan data mahasiswa (Nama, NIM, Jurusan)
- Mencatat nilai mata kuliah
- Mengonversi nilai angka ke nilai huruf (A–E)
- Menampilkan informasi lengkap mahasiswa dan nilainya

# Konsep OOP yang Digunakan
- **Class & Object** — Mahasiswa, NilaiAkademik
- **Konstruktor __init__** — inisialisasi atribut
- **Encapsulation** — atribut privat dengan awalan _
- **Property & Setter** — validasi saat mengubah nilai atribut
- **Class Method** — menghitung jumlah mahasiswa
- **Static Method** — konversi nilai angka ke huruf

# Teknologi
- Bahasa Pemrograman: **Python**
- Tidak memerlukan database atau GUI

2. Jalankan dengan perintah:
